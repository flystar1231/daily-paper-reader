## 摘要
生成式视频模型的最新进展显著提升了视频物体移除的视觉真实感，然而评估协议仍聚焦于掩码区域的保真度，将移除视为局部修复。在真实场景中，物体移除是一种因果干预：消除一个物体也需要移除其引发的物理效应，如阴影、反射、光照变化、半透明现象和动态痕迹。现有基准缺乏对齐的干净参考，或局限于简化的合成设置，无法对因果一致性进行系统评估。我们提出了BeyondMasks，一个用于因果一致性视频物体移除的成对基准，包含时间对齐的合成与真实世界视频对，并带有干净的背景参考。该数据集涵盖多种光度、几何、体积和动态交互，并支持基于掩码和指令驱动的编辑。我们进一步提出了CORE，一种基于结构化视觉语言模型的评估协议，联合衡量物体消失与后续效应一致性，相比现有指标更贴近人类判断。对最先进方法的基准测试显示，尽管掩码区域保真度高，但在移除次要物理效应方面存在系统性失败，暴露了视觉合理性与因果正确性之间的差距。BeyondMasks将视频物体移除重新定义为因果场景一致性而非局部重建，并为其评估提供了统一框架。

## Abstract
Recent advances in generative video models have significantly improved visual realism in video object removal, yet evaluation protocols still focus on masked region fidelity, treating removal as local inpainting. In real scenes, object removal is a causal intervention: eliminating an object also requires removing its induced physical effects, such as shadows, reflections, illumination changes, translucency, and dynamic traces. Existing benchmarks lack aligned clean references or remain limited to simplified synthetic settings, preventing systematic evaluation of causal consistency. We introduce BeyondMasks, a paired benchmark for causally consistent video object removal, consisting of temporally aligned synthetic and real world video pairs with clean background references. The dataset spans diverse photometric, geometric, volumetric, and dynamic interactions, and supports both mask based and instruction driven editing. We further propose CORE, a structured vision language model based evaluation protocol that jointly measures object disappearance and after effect consistency, aligning more closely with human judgments than existing metrics. Benchmarking state of the art methods reveals systematic failures in removing secondary physical effects despite high masked region fidelity, exposing a gap between visual plausibility and causal correctness. BeyondMasks reframes video object removal as causal scene consistency rather than local reconstruction and provides a unified framework for its evaluation.

### 2. 论文提出的方法论

**2.1 BeyondMasks 基准数据集**
- 包含 **180 个时间对齐的成对视频序列**：
  - **90 个合成场景**：使用 Veo 3 视频编辑能力，先生成无物体的干净背景视频，再通过受控编辑插入目标物体及其物理交互，保证两序列仅因物体介入而不同。
  - **90 个真实场景**：通过三脚架固定相机，背靠背拍摄“有物体”与“移除物体后”的视频，保持几何、光照与场景构成不变。
- 每个样本包含：物体存在视频、干净背景参考、逐帧物体掩码、以及验证过的文本指令提示。
- 支持**基于掩码**和**基于文本指令**两种编辑范式。

**2.2 因果后效分类体系**
按照物理交互机制划分为七类：
| 类别 | 描述 |
|---|---|
| 阴影（Shadow） | 物体遮挡光照产生的投影，需要恢复无阴影的光照场 |
| 反射（Reflection） | 镜面/水面/玻璃上的直接或间接反射痕迹 |
| 半透明（Translucent） | 玻璃等半透明物体造成的部分遮挡与光透射调制 |
| 蒸汽/散射（Steam/Scattering） | 蒸汽、烟雾等体积介质的弥散时变痕迹 |
| 因果物理效应（Causal） | 水波、灰尘轨迹、位移物体、脚印等动态痕迹 |
| 光源效应（Light source） | 物体发光时需补偿局部光照变化 |
| 无明确后效（No explicit after-effect） | 对照组，评估纯物体移除 |

**2.3 掩码标注策略**
- 掩码由 SAM2 + CoTracker 3 通过半自动流水线生成，并经过人工交叉审校。
- **关键设计**：掩码仅覆盖目标物体本身，**刻意排除阴影、反射等后效区域**，迫使模型通过物理推理而非显式监督来消除后效。

**2.4 CORE 评估协议（Causal Object Removal Evaluation）**
- 使用预训练视觉语言模型（VLM，默认 Gemini 3.1）作为评判者，输入三段视频：物体存在视频、干净背景参考、模型输出视频。
- 分解为两个互补分数：
  - **ObjectScore（CORE-OS）**：物体消失完整性与背景恢复合理性。
  - **AfterEffectScore（CORE-AES）**：阴影、反射、光照变化、动态扰动等物理痕迹是否被消除。
- VLM 在固定结构化提示下执行四步推理：识别目标与后效 → 分析 GT 背景 → 与输出做自然度对比 → 分类残余错误来源；最终给出 1–5 分制评分。
- 该评估将 VLM 打分从“观察式真实感评估”转化为“结构化干预验证”。

### 6. 论文的主要结论与发现

- **传统像素指标无法反映因果正确性**：LPIPS 相近的方法在阴影/反射消除上差异显著，PSNR/SSIM 高得分并不代表物体及后效被正确移除。
- **当前方法存在系统性缺陷**：绝大多数方法能成功移除物体本体，但**经常遗留阴影、反射、光照变化等二次物理痕迹**——高掩码保真度与低物理一致性并存。
- **后效类别难度差异明显**：半透明与蒸汽/散射类后效的 CORE-AES 分数最低，动态扩散型物理过程对现有方法挑战最大。
- **掩码式管道存在上下文丢失问题**：许多方法在推理前将被掩码区域置零，丢弃了半透明物体后原本可见的背景信息，迫使模型幻觉而非恢复内容。
- **CORE 与人类判断的一致性显著高于像素指标**：CORE Gemini（OS 0.62 / AES 0.73）和 CORE GPT（0.60 / 0.76）接近人类标注者间的一致性（0.69 / 0.79），且跨推理运行稳定（ICC 0.808/0.882）。
- **ReMOVE 与 CFD 等图像级指标同样失效**：其对视觉上连贯但因果不正确的输出给出相似的高分，无法区分真实移除质量。

### 7. 优点

- **问题重构的洞察力**：将物体移除从“局部重建”升维为“反事实场景渲染”，概念框架清晰且具有领域普适性。

- **支持指令式编辑**：同时适配掩码与文本提示，顺应视频基础模型的发展趋势。
