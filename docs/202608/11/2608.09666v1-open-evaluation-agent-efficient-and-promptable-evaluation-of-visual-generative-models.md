## 摘要
视觉生成模型的最新进展已实现高质量图像和视频的生成，但评估这些模型通常需要对成百上千张图像或视频进行采样，计算成本高昂。现有评估方法还依赖于僵化的流程，忽视了用户的具体需求，并提供无清晰解释的数值结果。模拟人类仅从少量样本中快速形成对模型能力印象的方式，我们提出评估智能体框架，该框架采用类似人类的策略进行高效、动态、多轮评估，提供详细且针对用户的分析。给定自然语言评估请求，智能体将其分解为子方面，生成针对性提示，从被评估模型中采样图像或视频，调用合适的评估工具，并根据观察到的证据迭代更新其计划，涵盖预定义的基准维度和开放式用户关注点。因此，该框架高效、可提示、可解释，并且跨模型和工具可扩展。实验表明，评估智能体将评估时间减少到传统方法的10%，同时提供可比较的结果。我们进一步通过构建EA-CoT-10K语料库（源自多轮评估展开的历史条件步骤级指令调整记录），并基于Qwen2.5-3B-Instruct训练EA-3B作为本地规划骨干，引入开放评估智能体（Open-EA），该骨干保留了基于API的智能体的结构化推理、工具调用和总结协议，同时减少对专有骨干的依赖。实验在已建立的T2I/T2V基准和开放式查询上验证了基于API的智能体，并在四个域内和三个域外T2V生成器家族上评估Open-EA，显示出所学策略的部分跨家族迁移。

## Abstract
Recent advances in visual generative models have enabled high-quality image and video generation, but evaluating these models often demands sampling hundreds or thousands of images or videos, which is computationally expensive. Existing evaluation methods also rely on rigid pipelines that overlook specific user needs and provide numerical results without clear explanations. Mimicking how humans quickly form impressions of a model's capabilities from only a few samples, we propose the Evaluation Agent framework, which employs human-like strategies for efficient, dynamic, multi-round evaluations, offering detailed, user-tailored analyses. Given a natural-language evaluation request, the agent decomposes it into sub-aspects, generates targeted prompts, samples images or videos from the evaluated model, invokes suitable evaluation tools, and iteratively updates its plan from the observed evidence, covering both predefined benchmark dimensions and open-ended user concerns. The framework is thus efficient, promptable, explainable, and scalable across models and tools. Experiments show that Evaluation Agent reduces evaluation time to 10% of traditional methods while delivering comparable results. We further introduce Open Evaluation Agent (Open-EA) by constructing EA-CoT-10K, a corpus of history-conditioned step-level instruction-tuning records derived from multi-round evaluation rollouts, and training EA-3B from Qwen2.5-3B-Instruct as a local planning backbone that preserves the structured reasoning, tool invocation, and summary protocol of the API-based agent while reducing dependence on proprietary backbones. Experiments validate the API-based agent on established T2I/T2V benchmarks and open-ended queries, and evaluate Open-EA on four in-domain and three out-of-domain T2V generator families, showing partial cross-family transfer of the learned policy.

- **研究动机**：视觉生成模型（文本到图像、文本到视频）发展迅速，但对其评估面临两大痛点：  
  - **计算成本高**：传统评估（如 VBench、T2I-CompBench）需要预先定义数百至数千个测试样本，生成大量图像/视频，尤其是扩散模型采样慢，导致评估耗时巨大。  
  - **流程僵化、缺乏可解释性**：固定提示、固定评估维度，难以适应用户的开放需求；只输出单一数值（如 FID、FVD）或分数，用户难以获得有意义的洞察。  
- **核心思想**：模拟人类评估者的行为——只看少量样本即可快速形成对模型能力的印象，并通过交互式测试不断调整评估方向。本文提出 **Evaluation Agent** 框架，将“评估”本身转化为一个由 LLM 驱动的**动态、多轮、可提示、可解释**的智能体过程。  
- **整体含义**：为视觉生成模型评估提供了一种新范式，强调“按需评估”、“高效评估”和“可对话式评估”，并进一步通过训练本地开源骨干（EA-3B）降低对专有 API 的依赖，推动评估工具的开源与普及。

## 2. 方法论

### 2.1 核心框架：Evaluation Agent

- 整体流程分为两个阶段，形成迭代循环：
  1. **提案阶段（Proposal Stage）**  
     - **Plan Agent**：解析用户自然语言请求，分解为子方面（sub-aspect），决定评估方向，观察中间结果并迭代调整，最终生成总结；每一步需给出明确理由，终止时需说明证据充分性。  
     - **PromptGen Agent**：为每个子方面设计适合的生成提示（支持引用已有基准的官方提示），在开放式评估中同时设计生成提示和 VQA 问题。  
  2. **执行阶段（Execution Stage）**  
     - **视觉生成模型**：根据生成提示采样图像或视频。  
     - **评估工具箱（Evaluation Toolkit）**：集成可扩展的评估工具，包括 VBench 维度工具、T2I-CompBench 工具、以及基于 VLM 的 VQA 工具，用于开放式查询评估。  
- 每轮循环执行“**提出子方面 → 生成提示 → 采样 → 工具评估 → 观察结果 → 决定下一轮或终止**”，从而实现广度扩展（跨类别）或深度挖掘（更困难样本）的动态路径。

### 2.2 关键技术细节

- **动态多轮评估**：不预设固定测试集，而是根据中间观察不断改变探测方向，避免冗余测试，提高效率。  
- **VQA 工具化**：开放式评估中，PromptGen Agent 为每个采样样本设计针对性问题，通过 VLM 回答，将视觉内容转化为结构化文本证据，供 Plan Agent 推理。  
- **Open-EA 的本地化训练**：  
  - 构建 **EA-CoT-10K** 数据集：将多轮评估轨迹（rollout）拆解为**历史条件化的步骤级指令微调记录**，每条记录包含用户查询、历史观测、思考过程、工具选择、返回信息和最终总结，并使用 `<think>`、`<tool>`、`<information>`、`<summary>` 标签结构化。  
  - 数据过滤：先用确定性分数过滤掉生成质量极低、前后不一致的轨迹；再用 MLLM 作为裁判验证推理是否基于真实视觉证据，剔除幻觉、矛盾、漏判等样本。  
  - **训练 EA-3B**：基于 Qwen2.5-3B-Instruct 进行全参数监督微调，使用 LLaMA-Factory，训练 3 个 epoch，最大序列长度 4096，有效 batch size 64，学习率 1e-5，cosine 衰减，warmup 比例 0.1。最终得到可在本地运行、遵循相同评估协议的紧凑规划骨干。

## 6. 主要结论与发现

- **效率提升显著**：Evaluation Agent 可将评估时间降低到传统方法的约 10%，采样数量从数千降到约 25 个，同时保持较高的分档准确性（多数维度 Within-1 准确率在 80%–100%）。  
- **动态评估有效**：通过多轮迭代、中间观察和调整提示，能够发现模型的细微优势与缺陷，优于固定测试集。  
- **开放查询可行**：使用 VQA 工具能将开放式问题转化为可推理的观测，支持对用户具体需求的定制化评估。  
- **Open-EA 可迁移但有限**：训练出的 EA-3B 能遵循相同协议，域内 Exact/Within-1 为 41.3%/77.3%，域外降至 31.1%/64.9%，说明**粗粒度能力分档**比**精确层级校准**迁移更可靠。  
- **难点维度明确**：全局质量（如 Overall Consistency、Temporal Style）评估较准，而细粒度语义维度（Object Class、Human Action、Spatial Relationship）准确率很低，提示未来需要更多提示多样性和更好的层级校准。

## 7. 优点

- **范式创新**：将视觉生成模型的评估从“固定基准打分数”转变为“可对话、可定制、可解释”的智能体过程，模拟人类评估策略。  
- **高效**：采样量减少约两个数量级，评估时间缩短超过 90%，适合快速迭代和模型比较。  
- **可提示与灵活**：接受开放的自然语言查询，支持用户特定的能力维度评估。  
- **可解释**：输出包含评估轨迹、推理过程、中间观察和最终总结，而非单一数值，方便非专家理解。  
- **开放与可扩展**：评估工具箱模块化，可随时集成新工具；代码、数据、模型全部开源，有利于社区复现和进一步发展。  
- **数据-训练闭环**：将 proprietary 模型的评估轨迹转化为可训练数据集（EA-CoT-10K），是“用智能体教智能体”的典型案例，减少了对专有 API 的依赖。  
- **诚实分析**：对 Open-EA 的域外泛化和难点维度进行了详细剖析，不回避性能短板。

## 8. 不足与局限

- **依赖 LLM/VLM 能力**：Plan Agent 的推理质量、PromptGen 的提示设计、VQA 工具的准确性都会影响最终评估结果，当前框架无法保证绝对可靠，且存在幻觉或错误工具选择的可能。  
- **Open-EA 性能有限**：Exact 准确率较低（域内 41.3%、域外 31.1%），细粒度语义维度（如 Object Class、Human Action）准确率极低，尚不能完全替代 API 版本。  
- **跨域迁移不足**：T2I 数据未参与训练，EA-3B 无法直接用于图像模型评估；域外 T2V 生成器性能衰减明显。  
- **评估维度受限**：实验主要围绕 VBench 和 T2I-CompBench 的现有维度，对更广泛的能力（如物理常识、时空连贯性、长视频）覆盖不足。  
- **缺少与同类方法的对比**：未与其他 agentic 评估方法（VideoGen-Eval、VideoArgus 等）在相同基准上做对比，难以判断相对优劣。  
- **成本透明性不足**：未报告模型训练的具体硬件配置和计算量；Open-EA 端到端耗时因生成器不同差异巨大（可达 144 分钟）。  
- **主观偏差风险**：开放式查询评估依赖人工构建的数据集标签和 VLM 回答，结论可能受主观影响；分档制评估损失了精确数值信息。  
- **规模有限**：EA-CoT-10K 仅约 1 万条记录、14 个训练轨迹来源，数据多样性可能不足以支持更强的泛化。
