## 摘要
视频世界模型根据当前观测和用户动作模拟未来状态。近期系统在长序列上展示了令人印象深刻的视频一致性和动作可控性。然而，公平地比较这些交互式模型仍然具有挑战性。在实践中，人类玩家通常通过追求长时程目标来进行交互，以评估世界模型。例如，用户可能旋转360度以检查环境是否保持一致，或走入水中并检查是否生成了逼真的水波纹。为实现同一目标所需的动作序列在不同模型之间可能差异显著，这使得固定的动作条件评估不适合跨模型比较。为解决这一问题，我们采用多模态智能体玩家与世界模型交互，以实现指定的长时程目标。基于这一范式，我们推出了PlayWorld，一个提供171个场景的基准测试，每个场景都有明确的目标。为全面评估性能，我们从四个核心维度对模型进行评估：几何一致性、交互保真度、视野外演变和洞察演变。此外，我们还纳入了视频质量和可控性的基本能力指标。对九个最先进世界模型的实验表明，当前模型在长时程交互目标上仍不可靠，尤其是在保持空间一致性和持续状态演变方面。代码和数据可在https://github.com/kxding/PlayWorld获取。

## Abstract
Video world models simulate future states conditioned on current observations and user actions. Recent systems have demonstrated impressive video consistency and action controllability over long sequences. However, fairly comparing these interactive models remains challenging. In practice, a human player typically evaluates a world model by pursuing long-horizon objectives through interaction. For example, a user may turn around 360 degrees to see whether the environment remains consistent, or walk into the water and inspect whether realistic water ripples are generated. The action sequence required to achieve the same objective may vary substantially between models, making fixed action-conditioned evaluation unsuitable for cross-model comparison. To address this, we employ multi-modal Agent Players to interact with world models toward specified long-horizon objectives. Building on this paradigm, we introduce PlayWorld, a benchmark providing 171 scenarios, each with a specified objective. To evaluate performance thoroughly, we assess models along four core dimensions: geometry consistency, interaction fidelity, out-of-sight evolution, and insight evolution. In addition, we incorporate basic ability metrics for video quality and controllability. Experiments across nine state-of-the-art world models reveal that current models remain unreliable on long-horizon interactive objectives, particularly in maintaining spatial consistency and persistent state evolution. Code and data are available at https://github.com/kxding/PlayWorld.

## 1. 论文的核心问题与整体含义

视频世界模型（Video World Models）能够根据当前观测和用户动作模拟未来状态，近年已在视频一致性和动作可控性上取得显著进展。然而，如何公平比较不同的交互式世界模型成为一个关键挑战：

- **固定动作序列评估范式不可靠**：同一目标（如“原地旋转360度”“走入水中”）在不同模型中所需的动作数量、时长和粒度差异很大。例如，相同的三条转向命令在一个模型中可能完成全周旋转，在另一个模型中只能转半圈，导致几何一致性分数不可比。
- **缺少闭环适应机制**：现有基准多采用预定义轨迹或固定动作序列，无法针对模型差异在线调整执行，也难以完成更复杂的动作模式（如绕雕像公转同时保持注视方向）。
- **闭源模型评估困难**：Genie 3、HappyOyster 等闭源模型仅通过 Web 界面提供交互，人工交互成本高且易引入偏差。

针对上述问题，论文提出 **PlayWorld**：一个基于多模态 **Agent Player（智能体玩家）** 与世界模型交互、面向长时程目标的自动化评估基准，旨在模拟人类玩家的真实评估方式。

## 2. 论文提出的方法论

### 2.1 核心思想

以人类玩家追求高层长时程目标的方式评估世界模型，而不是机械地检查预定义动作是否被执行。每个评估案例提供：

- **初始世界**：一张真实场景图片（来自 Pexels 或 Google Images）；
- **场景相关的长时程目标**：如“绕雕像公转一圈”“走进水里”“转动相机观察饼干上的糖霜有没有变多”；
- **基础动作序列**：用 W/A/S/D、↑/↓/←/→ 和 WAIT 表示的共享初始参考。

### 2.2 Agent Player 设计

Agent Player 由两部分构成：

| 组件 | 功能 |
|---|---|
| **多模态 Agent 模型**（如 Claude Haiku） | 观察生成帧、既有动作历史、场景描述和目标，决定下一步动作调整 |
| **Agent 接口** | 将 Agent 决策翻译为各世界模型的本地控制输入，执行动作并返回观测帧，形成闭环交互 |

Agent 模型可做出五类决策：

- **Keep**：保持当前动作或按计划推进；
- **Stop**：达到预期视觉状态时提前终止当前动作；
- **Extend**：需要更多移动时延长动作持续时间；
- **Correct**：观测状态偏离参考时修正或跳过下一动作；
- **End**：目标完成后终止评估。

控制策略为 **Preset + Agent**：以人类标注的基础动作序列为参考（Preset），同时根据生成观测在线适应调整（Agent）。相比纯预设（Preset Only）和纯在线规划（Agent Only），该策略轨迹得分和人类偏好最高（见表4），既能保持跨模型评估一致性，又能适应模型差异。

### 2.3 VQA Rubric 验证器

使用 Gemini 3.1 Pro 对每个生成视频回答样本特定的 Yes/No 问题，按加权方式聚合并映射到 1–5 分。评测覆盖四个核心维度：

1. **几何一致性（Geometry Consistency）**：先验证轨迹有效性，再看场景身份保持（纹理、颜色、形状）和空间关系（相对位置、布局）。
2. **交互保真度（Interaction Fidelity）**：先验证主体是否可动并到达交互区域，再看接触碰撞、运动学合理性（如脚不漂浮）、视觉反馈（如水花、水深度变化）。
3. **视线外演变（Out-of-sight Evolution）**：目标离开视野后是否保持身份一致并在隐藏期合理演变（如苹果去皮持续进行、糖霜变多）。
4. **洞察演变（Insight Evolution）**：在无明确动作轨迹的持续观察中，主体是否持续推进状态（如排队结账、厨师摆盘），且场景变化合理。

### 2.4 基本能力评估

引入 7 个视频质量指标（美学质量、成像质量、运动平滑度、时间闪烁、时间一致性、深度稳定性、主体一致性）和 2 个动作可控性指标（平移通过率、旋转通过率），并转换为 Basic Ability Score。

## 6. 论文的主要结论与发现

1. **持续世界演变是当前模型的主要瓶颈**：所有模型在视线外演变和洞察演变维度得分偏低。目标离开视野后，可能不变化、复位或以错误位置返回，语义状态无法在长时间跨度中持续演化。
2. **长时程回访暴露全局空间不一致**：绕泰姬陵旋转 360° 时，模型可能在不同视角反复生成同一地标的多个副本，破坏空间唯一性和全局场景拓扑。模型依赖局部外观连续性和短程运动线索，缺乏可靠的全局三维表征。
3. **交互保真度限于简单碰撞响应**：第三人称模型可在障碍边界停止，但第一人称控制可能直接穿过固体障碍；走入水中等复杂交互往往无法产生预期物理或视觉反馈。
4. **轨迹控制能力与世界模型能力可以脱节**：SANA-WM 轨迹通过率较高但 rubric 分数一般，说明“能到达目标区域”不等于“具备一致的内存、空间和物理表现”。
5. **自动指标只能测试基本能力**：各模型视频质量指标普遍接近满分，但动作可控性仍不精确；深度稳定性和主体一致性在模型产生极少相机运动时也会偏高，不能反映长时程目标是否完成。

## 7. 优点

- **评估范式创新**：以人类玩家的长时程目标为评估核心，相比固定轨迹更贴近真实使用场景，解决了跨模型动作粒度差异导致的不可比问题。
- **闭环自适应控制**：Preset + Agent 策略兼顾了跨模型一致性和在线自适应性，Agent 修改动作比例仅 12–15%，确保比较公平性的同时保留灵活性。
- **多维度的全面测评**：几何一致性、交互保真度、视线外演变、洞察演变四个维度各有明确的验证门控和鲁棒 VQA 评分规则，有效分离“轨迹到达”和“世界能力”两个层面的差异。
- **支持闭源模型评估**：通过浏览器自动化将 Web 界面模型纳入标准化评测，扩大了覆盖率。
- **人类验证充分**：5 人评分、600 个判断、95.8% 的多数一致性，VQA 分数与人类偏好在各维度均显著正相关，说明自动化验证是可靠的。
- **基准公开可用**：提供代码、数据、排行榜和项目页面，复现成本较低。

## 8. 不足与局限

- **验证器的模型依赖**：VQA 验证依赖于 Gemini 3.1 Pro 的视觉理解能力，对该模型无法正确判断的问题（如复杂物理因果关系）存在系统性偏差风险；建议在评估预算允许时多次评分取平均。
- **Agent Player 的决策延迟**：基于多模态 LLM 的逐步决策可能引入等待时间，影响交互节奏和动作执行时长，尤其在资源受限的部署环境中。
- **闭源模型的评估复杂度高**：Web 界面操作依赖页面加载和渲染状态检查，实验可复现性受制于外部服务更新和网络环境；不同闭源模型的输入条件差异（如 HY-World2 需要全局场景建模能力）导致部分案例被跳过。
- **某些模型无法按预期协议评估**：Hunyuan-GameCraft-2 要求每个生成块必须有非空动作输入，无法完成洞察演变中需要被动观察的场景，影响参与度公平性。
- **人类验证的规模和一致性有限**：Fleiss κ 仅 0.434（总体），处于中等水平；每维度仅有 30 对视频，结论的外推性有一定限制。
- **未提供算力细节**：缺少对 GPU 类型、数量、推理时间和成本的详细记录，不利于社区精确复现和横向比较。
- **主体类型分布不均衡**：机器人仅 3 例、动物 14 例，相对人类（57 例）和环境（49 例）明显偏少，评估结论对外围主体类型的适应性有限。
